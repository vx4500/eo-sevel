Installation de cloudflared

{% if installe %}installé{% else %}à installer{% endif %}

À faire une seule fois, dans un terminal du serveur (compte avec sudo). Copiez chaque ligne l’une après l’autre :

{% for ligne in [ "curl -L -o /var/tmp/cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb", "sudo dpkg -i /var/tmp/cloudflared.deb", "sudo ln -sf /usr/bin/cloudflared /usr/local/bin/cloudflared", "cloudflared --version" ] %}
{{ ligne }}
{% endfor %}

La dernière ligne doit afficher « cloudflared version … ». Rechargez ensuite cette page : l’état passe à « installé ». Pas besoin de cloudflared service install : c’est EO_Sevel qui lance le tunnel.

Mise à jour plus tard : relancer les deux premières lignes, puis « Redémarrer le tunnel ».

  1. Sur one.dash.cloudflare.com → Networks → Tunnels → Create a tunnel (type Cloudflared), nommez-le « eo-sevel ».
  2. Copiez la commande affichée (elle contient le jeton eyJ…) et collez-la ci-dessous, en entier si vous voulez.
  3. Dans le tunnel → Public Hostname : votre adresse → service HTTP, URL localhost:8080.
