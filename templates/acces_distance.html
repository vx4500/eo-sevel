Le tunnel tourne dans EO_Sevel : il repart tout seul après une coupure de courant, sans Home Assistant.

Réglages

  1. Sur one.dash.cloudflare.com → Networks → Tunnels → Create a tunnel (type Cloudflared), nommez-le « eo-sevel ».
  2. Copiez la commande affichée (elle contient le jeton eyJ…) et collez-la ci-dessous, en entier si vous voulez.
  3. Dans le tunnel → Public Hostname : votre adresse → service HTTP, URL localhost:8080.

Si l’ancien tunnel de Home Assistant utilise la même adresse, retirez-la de l’ancien tunnel puis arrêtez l’add-on Cloudflared de Home Assistant.
