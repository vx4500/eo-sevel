{% if regle.id %}{{ regle.nom }}{% else %}Nouvelle règle{% endif %}

Une règle, c'est une phrase : quand quelque chose arrive (une sonde, une entrée, un relais…), alors le logiciel fait une action (allumer, éteindre, envoyer un SMS). Exemple : quand la température de Mater 1 dépasse 28 °C depuis 5 min, alors allumer la brumisation, et l'éteindre quand ça redescend.

{% if regle.id %}{% endif %}

① Quand… (ce qu'on surveille)

Vide = à toute heure. La plage peut passer minuit (22:00 → 06:00).

② Alors faire… (l'action)

« Dès que c'est vrai » : l'action part quand la condition ① est remplie. « Quand ça redevient normal » : l'action part quand la condition ① n'est plus remplie — pratique pour éteindre ce qu'on a allumé ou prévenir que tout est rentré dans l'ordre.

{% if not sorties %}

Aucune sortie n'est encore autorisée à la commande : cochez « Autoriser la commande » sur un relais dans Ipx800v5 → Relais. Les SMS restent possibles.
