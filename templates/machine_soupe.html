Installer le service d’écoute sur l’hôte Proxmox

Dans Proxmox : cliquez sur le nœud proxmox → Shell, puis collez ces deux commandes l’une après l’autre.

1. Télécharger le programme d’écoute :

curl -fsS "{{ adresse }}/api/soupe/script?jeton={{ jeton }}" -o /usr/local/bin/soupe-ecoute && chmod 755 /usr/local/bin/soupe-ecoute

2. Le lancer en service (redémarre tout seul) :

printf '[Unit]\nDescription=Ecoute machine a soupe pour EO_Sevel\nAfter=network-online.target\n[Service]\nExecStart=/usr/bin/python3 /usr/local/bin/soupe-ecoute\nRestart=always\nRestartSec=10\n[Install]\nWantedBy=multi-user.target\n' > /etc/systemd/system/soupe-ecoute.service && systemctl daemon-reload && systemctl enable --now soupe-ecoute

Vérifier : systemctl status soupe-ecoute — la phase doit s’afficher ici en quelques secondes. Le service ne fait que lire une copie du trafic USB : le PC Mega-feeder continue de piloter la machine normalement.
